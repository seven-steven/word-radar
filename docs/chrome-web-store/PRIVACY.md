# PRIVACY.md — 隐私政策

> 与扩展真实行为一致的隐私声明（依据见 [FACTS.md](./FACTS.md)）。最后更新：2026-08-20。以 `pnpm verify:claims` 断言不含禁词表措辞。

WordRadar（单词雷达）是一款浏览器扩展，帮助用户从英文网页提取生词并推送到「不背单词」生词本。本政策如实说明扩展处理了哪些数据、去向何处。

## 我们处理什么数据

1. **当前网页内容（仅用户主动触发时）**
   - 只有当你点击扩展图标（或点击弹窗内采集按钮）时，扩展才会读取当前标签页的页面文本（整页正文或你选中的段落）。
   - 提取与词形还原完全在你的浏览器本地完成。
   - 扩展不在后台自动读取任何页面，不记录你的浏览历史。

2. **生词数据**
   - 提取出的生词先存入你浏览器本地的词库（IndexedDB）。
   - 当你启用推送后，待推生词会逐个发送至不背单词（bbdc.cn）的生词本接口；加词前会向 langeasy.com.cn 查询单词释义。
   - 除此之外，我们不向任何其他服务器发送你的数据。

3. **登录凭证（cookie）**
   - 推送依赖你在 bbdc.cn 的浏览器登录状态；请求发出时由浏览器原生附带 bbdc.cn 的 HttpOnly cookie。
   - 扩展代码不读取、不存储、不转发 cookie 值，也不要求你在扩展内输入任何密码。

4. **设置与统计**
   - 扩展设置保存在 chrome.storage.local，词库与计数保存在 IndexedDB——全部仅在你本地浏览器内。

## 我们不做什么

- 无遥测：不上报错误、不上报使用行为、不统计任何用户数据。
- 无第三方分析、无广告 SDK、无远程代码——扩展运行的所有代码均随安装包分发。
- 不出售、不共享、不将你的数据用于扩展功能之外的任何用途。

## 数据存储与删除

- 所有本地数据（词库、设置、计数）仅存在于你的浏览器中。
- 导出 CSV 备份由你主动触发，文件保存在你指定的位置。
- **删除方式**：卸载扩展即自动清空全部本地数据；已推送到不背单词生词本的词可在其官网/App 内自行管理。

## 权限说明

扩展仅申请最小必要权限（storage / activeTab / scripting，及 bbdc.cn、langeasy.com.cn 两个域名访问），逐条理由见商店页面的权限说明或 [STORE-LISTING.md](./STORE-LISTING.md)。
