# Chrome Web Store 必交材料清单（平台层规范）

> 平台规范以 Developer Dashboard 实测为准（实测 dump 2026-08-22，原始文件位于 `/tmp/cws-dumps/`，权威字段口径见 [`docs/chrome-web-store/research-cws-dashboard-fields.md`](../../docs/chrome-web-store/research-cws-dashboard-fields.md)）。本文件给出材料规范的基线，给 SUBMISSION / STORE-LISTING / PRIVACY 文案层提供"哪些字段、什么上限、哪里手填/自动"的参考。

## 1. Dashboard 主结构（实测 2026-08-22）

WordRadar 商品编辑入口由 **5 个 tab + 2 个左侧 sidebar 独立页** 组成：

| 位置     | Tab / 页面              | URL 后缀                 | 作用                                                       |
| -------- | ----------------------- | ------------------------ | ---------------------------------------------------------- |
| tab      | 状态                     | `/edit/status`           | 当前版本状态 / 审核进度                                      |
| tab      | 文件包                   | `/edit/package`          | 上传新包；上传后自动显示版本/内容类型/权限/CRX/公钥            |
| tab      | 商品详情                 | `/edit/listing`          | 商店展示信息（标题/摘要/说明/类别/语言/图片/URL/成人内容）   |
| tab      | 隐私权                   | `/edit/privacy`          | 单一用途/权限理由/远程代码/数据使用/隐私政策 URL              |
| tab      | 分发                     | `/edit/distribution`     | 付款方式/公开范围/地区                                       |
| sidebar  | 访问权限                 | （左侧导航）              | 哪些 Google 账号可访问                                       |
| sidebar  | **测试说明**             | `/testcredentials`       | **测试账号 + 说明**（必填独立页，非 tab）                     |

## 2. Store listing（商品详情 tab，语言集 = zh）

本项目 Listing 语言集声明为**简体中文（zh）**——扩展 UI、README、文档均为中文（FACTS.md §4）。STORE-LISTING.md 各 ```text 块是文案层唯一来源，直接复制粘贴。

### 2.1 产品详情（自动 vs 手填分区）

| Dashboard 字段    | 自动/手填 | 上限（实测计数）               | 文案层来源                                                  |
| --------------- | --------- | ------------------------------ | ----------------------------------------------------------- |
| 标题            | **自动**（zip manifest.name） | 上限未在框内显示（实测未给出计数器），建议 ≤75 字符以保安全 | manifest.name = `WordRadar`                                  |
| 摘要            | **自动**（zip manifest.description） | 同上                            | 由 STORE-LISTING「简短描述」text 块控制                       |
| 说明            | 手填       | **16,000 字符**（实测 720/16,000） | STORE-LISTING「详细描述」text 块                             |
| 类别            | 手填单选   | 单选                            | STORE-LISTING「类别」text 块（当前 Dashboard 实测值 = 教育；约定目标 = 效率工具，见 [§6](#6-实测冲突与待决策)） |
| 语言            | 手填单选   | 单选                            | 本项目 = `中文（中国）`                                       |

> **实测发现**：标题与摘要**自动从 zip manifest 提取**，Dashboard 显示为"软件包中的标题 / 软件包中的摘要"两框（不可改 = 实际上**不建议覆盖**）。本项目策略 = **不覆盖**，以 manifest 为唯一来源（FACTS.md §3）。

### 2.2 图片资源

| 素材       | 画布尺寸            | 格式                                              | 数量       |
| ---------- | ------------------- | ------------------------------------------------- | ---------- |
| 商店图标   | **128×128 像素**     | PNG / JPEG（遵循图片指南）                          | 1 个        |
| 屏幕截图   | **1280×800 或 640×400** | **JPEG 或 24 位 PNG（无 alpha 透明层）**            | **1–5 张** |
| 小型宣传图块 | **440×280 画布**     | **JPEG 或 24 位 PNG（无 alpha 透明层）**            | 可选 1 个   |
| 顶部宣传图块 | **1400×560 画布**     | **JPEG 或 24 位 PNG（无 alpha 透明层）**            | 可选 1 个   |

> **新增 alpha 限制**：截图 / 宣传图块**不允许 alpha 透明层**。`pnpm screenshot` 产出需确保不带 alpha（必要时预处理）。

## 3. Privacy（隐私权 tab）

### 3.1 单一用途

| 字段           | 上限（实测） | 文案层来源                                       |
| -------------- | ------------ | ------------------------------------------------ |
| 单一用途说明   | **1,000 字符** | STORE-LISTING「单一用途描述」text 块              |

### 3.2 权限理由（**实测 = 4 框**）

> 实测：3 个 API 权限各一框 + **所有 host_permissions 合并为一个框** = **4 框**。

| Dashboard 输入框                  | 上限      | 来源                                                                          |
| --------------------------------- | --------- | ----------------------------------------------------------------------------- |
| 需请求 storage 的理由              | **1,000** | STORE-LISTING「权限理由」text 块第一条                                          |
| 需请求 activeTab 的理由            | **1,000** | 第二条                                                                          |
| 需请求 scripting 的理由            | **1,000** | 第三条                                                                          |
| 需请求**主机权限**的理由            | **1,000** | **第四条 + 第五条**（bbdc.cn + langeasy.com.cn **合并写入同一框**）            |

### 3.3 远程代码声明

| 控件        | 形态                                                  | 本项目选择 |
| ----------- | ----------------------------------------------------- | ---------- |
| 您正在使用远程代码吗？ | 单选：`不，我并未使用远程代码` / `是的，我在使用远程代码` | **`不`**   |
| 理由        | textarea，**0/1,000**，仅"是的"时填写                  | 留 0 字符 |

### 3.4 数据使用（实测 **9 类**）

> 9 类按 Dashboard 出现顺序，勾选项字面中译。

| Dashboard 标签       | 英文对应                            | 本项目勾选 |
| -------------------- | ------------------------------------ | ---------- |
| 个人身份信息         | Personally identifiable information  | 不勾       |
| 健康信息             | Health information                   | 不勾       |
| 财务和付款信息       | Financial and payment information    | 不勾       |
| 身份验证信息         | Authentication credentials           | **勾**     |
| 个人通讯             | Personal communications              | 不勾       |
| 位置                 | Precise location                     | 不勾       |
| 网络记录             | Website history                      | 不勾       |
| 用户活动             | User activity                        | 不勾       |
| 网站内容             | Website content                      | **勾**     |

### 3.5 Limited use 强制确认（**必勾 3 条**）

| # | 文案                                                                      | 必勾 |
| - | -------------------------------------------------------------------------- | ---- |
| 1 | 我不会出于已获批准的用途之外的用途向第三方**出售或传输**用户数据            | ✓   |
| 2 | 我不会为实现与我的产品的**单一用途无关的目的**而使用或转移用户数据          | ✓   |
| 3 | 我不会为**确定信用度或实现贷款**而使用或转移用户数据                        | ✓   |

> 实测 Dashboard 强制三选全勾，否则不能提交。

## 5. 测试说明（独立页，URL `/testcredentials`）

> 注意：**不是 "Account access" tab**——实测命名是"测试说明"独立页，位于左侧 sidebar，URL 后缀 `/testcredentials`。SUBMISSION / skill 文档统一以"测试说明（独立页）"称呼。

| 字段     | 上限（实测） | 备注                                                |
| -------- | ------------ | --------------------------------------------------- |
| 用户名    | **100** 字符  | "用于测试扩展程序的用户名"                          |
| 密码      | **100** 字符  | "提供的用户名对应的密码（如果有）"                  |

## 7. 上传包

- `dist/word-radar-<version>-chrome.zip`（`pnpm build && pnpm package` 产出；`pnpm verify:zip` 断言结构）。
- 上传后 Package tab **自动读取**版本/内容类型/权限列表(权限 storage, activeTab, scripting, host permission)/CRX 文件/公钥——无需手填。

## 8. 人工填写项（绝不入仓库）

- 测试账号（bbdc 账号 + 登录方式）：仅填 Developer Dashboard「测试说明」独立页的凭证字段。仓库任何文件不得出现账号/密码明文（FACTS.md §6）。
